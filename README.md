# 😊 Emotion Detection using Machine Learning

## 📌 Project Overview

This project focuses on detecting human emotions from facial expressions using Machine Learning techniques. It analyzes input images (or real-time webcam feed) and classifies emotions such as **Happy, Sad, Angry, Surprise, Neutral**, etc.

---

## 🎯 Objectives

* To build a model that can recognize human emotions accurately
* To apply Machine Learning algorithms in image classification
* To demonstrate real-time emotion detection using a webcam

---

## 🧠 Features

* 📷 Detect emotions from images
* 🎥 Real-time emotion detection using webcam
* ⚡ Fast and efficient prediction
* 📊 Multiple emotion categories

---

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Libraries & Tools:**

  * OpenCV
  * NumPy
  * TensorFlow / Keras 
* **IDE:**  Jupyter Notebook

---

## ⚙️ Installation & Setup

1. Clone the repository:

```
https://github.com/adarshmehta001/emotion_detection.git
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Run the project:

```
python main.py
```

---

## ▶️ How It Works

1. Capture image using webcam or load an image
2. Detect face using OpenCV
3. Preprocess the image
4. Pass it to the trained ML model
5. Display predicted emotion

---

## 📊 Output

The system displays the detected emotion label on the face in real-time.

---

## 🚧 Limitations

* Accuracy depends on lighting conditions
* Limited dataset may reduce performance
* Works best with clear frontal faces
